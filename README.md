# KIF/SFEN ツール集

KIF棋譜の変換とSFEN局面の閲覧を一つにまとめた静的プロジェクトです。ブラウザのみで動作します。

## 構成
- `index.html` : 入口ページ
- `kif_to_sfen/` : KIF → SFEN 変換・分析ツール
- `sfen_viewer/` : SFEN 局面ビューア
- `data_manager/` : SFEN データ管理

## 使い方
1. ブラウザで `index.html` を開きます。
2. 使いたいツールを選択します。

### KIF → SFEN 変換
- KIF/KIFUファイルの変換
- KIFテキストの貼り付け変換
- フォルダ内のKIF一括処理（CSV出力）
- 一括処理では「先手勝利数/後手勝利数/引分数」と「対象ユーザーの先手/後手回数」を集計可能
- 一括処理の出力はCSV/JSONL（軽量）を選択可能
- KIFのヘッダから対局日時を抽出し、出力に含める
- 出力に user_name 列を含め、ユーザー単位管理に対応

### SFEN 局面ビューア
- CSV/JSON/JSONLの読み込みに対応
- 出現回数や開始手数でのフィルタ
- コメントの付与と保存
- 先手勝率の表示、対象ユーザーの先手/後手回数の表示
- データ保存はIndexedDBで管理
- ユーザー名単位でデータ管理
- 対局日時で期間フィルタが可能
- 任意期間のデータ削除に対応
- データ登録は重複のない局面のみ追加
- 期間指定ボックスは登録データの最古/最新日を自動セット
- ビューア画面とデータ管理画面を分離（sfen_viewer/ と data_manager/）

## 注意事項
- 一括処理のフォルダ選択は、ブラウザによって挙動が異なる場合があります。
- ローカルストレージを利用するため、ブラウザの保存容量に制限があります。
